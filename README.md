# 🍽️ Foodie's Hub

A modern and responsive restaurant website built using **HTML, CSS, and JavaScript**. This project showcases a complete front-end solution for a restaurant, focusing on user experience, design, and interactivity.

---

## 🚀 Features

* 🍔 Interactive Menu with Add-to-Cart functionality
* 🎨 Modern UI with smooth hover effects
* 📱 Fully responsive design (mobile-friendly)
* 👨‍🍳 About Page with restaurant story & specialties
* 📞 Contact Page with form, WhatsApp integration & Google Maps
* 🧭 Multi-page navigation with consistent layout
